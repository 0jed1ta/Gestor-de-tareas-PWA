Gestor de Tareas — proyecto acumulativo
Electiva - PWA · UPTC

Esta es la carpeta de trabajo principal. Cada guía se implementa aquí de
forma acumulativa; las carpetas gestor-de-tareas-sesionXX se usan únicamente
como referencia.

Estado actual: Sesión 22 completada
-----------------------------------
- Gestor de tareas funcional con persistencia estructurada en IndexedDB.
- Web App Manifest enlazado desde index.html.
- Nombre, colores, orientación y modo standalone configurados.
- Iconos de 192x192 y 512x512, incluido el icono maskable.
- Service Worker registrado con eventos install, activate y fetch.
- Recursos esenciales preparados durante la instalación.
- Respuesta desde caché para recursos disponibles y red como respaldo.
- Caché versionada como gestor-tareas-v2.
- Eliminación automática de versiones antiguas durante la activación.
- Estrategia Cache First aplicada a las solicitudes interceptadas.
- Recursos obtenidos desde la red guardados con cache.put().
- Estrategia Network First preparada para rutas de API.
- Estrategia Stale-While-Revalidate aplicada al shell de la aplicación.
- Estrategias enrutadas según el tipo de recurso solicitado.
- Base de datos versionada con índices por prioridad y título.
- Operaciones CRUD y consultas mediante cursor sobre las tareas.
- Notas privadas cifradas con AES-GCM y claves derivadas con PBKDF2.

Cómo abrirlo
------------
Este proyecto usa módulos de JavaScript y debe ejecutarse desde un servidor
local. Desde esta carpeta:

  python3 -m http.server 8080

Luego abre http://localhost:8080 en el navegador.
